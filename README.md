# Adam Omer — portfolio

Live at **https://mrcheesechase.github.io/**

Plain HTML/CSS/JS — no build step, hosted on GitHub Pages.

- `content.js` — **all the text, projects and experience live here.** Edit this to update the site.
- `index.html`, `styles.css`, `app.js` — layout, styling, routing, command palette.
- `cv.pdf` — generated by `python3 scripts/build_cv.py` (edit the content at the top of that script).
- `images/` — web-ready images only.

Preview locally:

    python3 -m http.server 8765
    # open http://localhost:8765

Publish changes: commit and push to `main` — GitHub Pages redeploys automatically.
